# MarketHub - Multi Vendor Marketplace

MarketHub is a full-stack multi-vendor e-commerce marketplace built using Next.js, Firebase, Firestore, AWS S3, and Razorpay.

## Features

### Buyer Features
- User Authentication
- Product Search
- Category Filtering
- Product Details Page
- Add to Cart
- Wishlist
- Buy Now
- Razorpay Payments
- Reviews & Ratings
- Similar Products
- Responsive Mobile UI

### Seller Features
- Seller Dashboard
- Add Products
- Edit Products
- Delete Products
- Multiple Product Images
- AWS S3 Image Uploads
- Real-Time Product Management

### Admin Features
- Admin Dashboard
- User Management
- Product Approval
- Product Moderation
- Order Monitoring
- Marketplace Analytics

## Tech Stack

Frontend:
- Next.js
- React
- TypeScript
- Tailwind CSS

Backend:
- Firebase Authentication
- Firestore Database

Cloud:
- AWS S3

Payments:
- Razorpay
